---
name: catchup
description: Resume work by reading recent context notes and identifying where the current project stopped and its next action.
---

Read [runtime guidance](../../references/runtime.md). Run `catchup` to get the
five newest notes, with their sections and source paths.

If a topic or session was specified, select the matching note; otherwise show
the recent titles and summaries and ask which work to resume. An explicit
request to resume the latest session already supplies that choice.

Present what was being done, useful decisions, unresolved Next Steps, and one
immediate action. Offer the relevant `projects/<name>/<name>_progress.md` if
more project detail would help. Use saved sections as evidence and state when
next steps are absent. If no notes exist, offer the extract-today workflow.
