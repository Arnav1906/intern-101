---
name: recall
description: Find saved project sessions about a topic and recover their findings, decisions, and next steps.
---

Read [runtime guidance](../../references/runtime.md). Run `recall "<query>"` to
search titles and all note sections case-insensitively. With no query, `recall`
lists the available notes.

Show matching dates, titles, short summaries, and file paths. For a selected
session, present its Summary, Key Decisions & Findings, and Next Steps. Load
the full document only when useful or requested. No matches means offer a
broader term; do not scan unrelated project histories.
